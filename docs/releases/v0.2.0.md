# mojo-proptest v0.2.0

**Released:** 2026-11-09 · **Commit:** `e095dc4` · **Previous:** [v0.1.1](v0.1.1.md)

## What it does

Property tests for Mojo in 149 lines: seeded generators, greedy shrinking, and a failure that names
the seed, the case number and the minimal value. `check(gen, prop, n=500, seed=1)`.

## Highlights

- The import is now `mproptest`, so it installs beside [bpr/proptest](https://github.com/bpr/proptest), which imports as `proptest`. The package keeps its name, `mojo-proptest`.

## Changes

### Changed
- Breaking: `from proptest import ...` becomes `from mproptest import ...`; the precompiled module is `mproptest.mojoc`.
- The failure message starts with `mproptest: falsified at case`.
