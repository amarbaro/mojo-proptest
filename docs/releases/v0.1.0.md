# mojo-proptest v0.1.0

**Released:** 2026-11-04 · **Commit:** `38f5898` · **Previous:** first release

## What it does

Property tests for Mojo in 149 lines: seeded generators, greedy shrinking, and a failure that names
the seed, the case number and the minimal value. `check(gen, prop, n=500, seed=1)`.

## Highlights

- A failure replays: `falsified at case i (seed=s); minimal: v`, and case i depends only on (seed, i).
- Generators that shrink: `Ints`, `Byte`, `Floats` (a quarter special values), `Strings` (UTF-8 safe), `Lists`, `OneOf`.
- Shrinking is bounded at 10,000 candidates, so a bad custom `Gen` cannot loop forever.

## Known limits

- One argument per property; several need `Lists` or a custom generator.
- Shrinking is greedy: the minimal value is a local minimum, not always the global one.
- Mojo 1.2 only (`mojo>=1.2.0,<1.3`).
